1. In WP Admin, go to: Contact > Add New
2. Title the form: "Free Local SEO Audit"
3. Paste the FORM TEMPLATE below into the "Form" tab
4. Paste the MAIL TEMPLATE into the "Mail" tab
5. Paste the MESSAGES into the "Messages" tab (optional)
6. Save the form and copy the generated shortcode (e.g. [contact-form-7 id="1234" title="Free Local SEO Audit"])
7. Replace the existing <form id="seo-audit-form"> block in front-page.php
   with:  <?php echo do_shortcode('[contact-form-7 id="XXXX" title="Free Local SEO Audit"]'); ?>

FRONT-PAGE.PHP REPLACEMENT SNIPPET
=====================================================================

Replace the existing <form id="seo-audit-form"> ... </form> block
inside the "Lead Magnet Section" of front-page.php with:

<?php echo do_shortcode('[contact-form-7 id="XXXX" title="Free Local SEO Audit"]'); ?>

(Replace XXXX with the actual form ID assigned by CF7.)

=====================================================================
NOTES
=====================================================================

- The class: attributes on CF7 tags let Tailwind utilities apply directly
  to the rendered inputs so the form keeps the current indigo/purple look.
- If you want to disable the auto-reply, simply uncheck "Mail (2)" in CF7.
- Once CF7 is live, you can safely remove:
    src/scripts/lead-magnet.js
    the wp_enqueue_script('lead-magnet', ...) line in functions.php
- Consider adding Flamingo (CF7 companion plugin) to store submissions
  inside WP, and/or a reCAPTCHA integration to cut spam.
